# Retro Windows Player

A browser-based Windows 98 desktop experience and launcher concept for classic PC games.

## Prototype

Open `index.html` in a modern browser or publish this repository with GitHub Pages. The prototype includes an animated boot screen, draggable desktop shortcuts, Start menu, windows, taskbar, simulated Explorer and Program Files folders, and sample game entries.

## Game compatibility

The sample games are illustrative entries only. This project does not yet execute Windows `.exe` files. Browser playback requires a compatible emulator/runtime and game data supplied by users. Do not upload or redistribute copyrighted game files unless you have permission.

## GitHub Pages

The included workflow publishes the repository root to GitHub Pages on pushes to `main`. In repository Settings → Pages, choose GitHub Actions as the source if not already selected.
